# Shorts, on your terms

An interactive Streamlit concept for a more accessible, user-controlled short video experience.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Push this folder to a GitHub repository, then create an app at [Streamlit Community Cloud](https://share.streamlit.io/) and select `app.py` as the entry point. The app has no secrets or external API requirements.

## Prototype features

- Feed with topic discovery, next-video navigation, playback state, caption toggle, and save action
- Explore page with searchable topic cards
- Saved collection view
- Settings for captions, interests, playback, personalization, and reduced motion

This is a frontend concept with sample content. It is not affiliated with YouTube.
